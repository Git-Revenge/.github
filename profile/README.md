Git Revenge is a desktop git client for Windows, macOS and Linux that stays fast on huge repositories. It drives the `git` you already have installed. There are no accounts, no cloud features and no AI.

**[Download the latest release](https://github.com/Git-Revenge/GitRevenge/releases/latest)** · [Read the docs](https://gitrevenge.com) · [Browse the source](https://github.com/Git-Revenge/GitRevenge)

Or install it with a package manager:

- **macOS:** `brew install --cask git-revenge/tap/gitrevenge`, from [our tap](https://github.com/Git-Revenge/homebrew-tap).
- **Ubuntu, Debian and RHEL:** `apt` or `dnf`, from the signed repositories at [packages.gitrevenge.com](https://packages.gitrevenge.com) ([source](https://github.com/Git-Revenge/packages)). The [install guide](https://gitrevenge.com/docs/guide/install#linux) has the one-time setup.

### Why use it

- **It copes with very large repositories.** On the Linux kernel (1.5M commits), the first screen of the graph arrives in under half a second.
- **It uses your setup.** Your git config, credential helpers and SSH agent all work as they already do.
- **It stays on your machine.** There's no telemetry and no sync. The only request it makes on its own is a check for a newer release at startup, and you can turn that off.
